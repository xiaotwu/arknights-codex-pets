# 克莱门莎 · Clementia

An *Arknights* fan-made animated companion. The normalized repository ID is `clementia`; the website ID is `arknights-clementia`. The pet uses the default operator costume, adapted into an anime chibi silhouette. Icy blue hair, golden eyes, paired manta-ray cephalic fins, a right-side gold clip and blue-gold earring, a left gold pauldron and left-hand blue-gold sword are the main identity cues. Her patient, composed warmth informs the animation; the gestures are a fan interpretation, not additional game canon.

## 游戏设定与气质

克莱门莎（Clementia）是《明日方舟》的阿戈尔六星近卫干员，本源近卫分支。她拥有军团长、执政官、总战争设计师的荣誉头衔，负责阿戈尔的陆上合作项目。头顶的成对结构应理解为蝠鲼的**头鳍**，与细长尾巴呼应，不是萨卡兹的角。基础信息与背景参见 [PRTS 角色页面](https://prts.wiki/w/%E5%85%8B%E8%8E%B1%E9%97%A8%E8%8E%8E) 的干员信息及人员档案。

她的亲切有礼与理性沉稳，与责任压力和不易放松的一面并存。档案与语音也展现了她对文化差异的留意、幽默的谈吐，以及安静休息的愿望。因此这份桌宠以**从容、细心、耐心而略带倦意的温和**为主要创作解读，避免把她演成冷漠的武器，或只会夸张卖萌的幼童。参见 [BWIKI 的档案与语音记录](https://wiki.biligame.com/arknights/%E5%85%8B%E8%8E%B1%E9%97%A8%E8%8E%8E)。

## 参考图与视觉取舍

用户提供的五张图包含早期造型、精二场景、柔光全身图、默认干员立绘和面部近景。最终以默认干员立绘和面部近景统一服装，其他图用于理解身体结构、配色和海洋意象，不将不同服装随机混入动画。

- **头部**：冰蓝色齐颈短发，发梢向外翘，侧分刘海；金色眼睛、尖耳、成对深蓝头鳍，鳍前缘或顶端为浅金色。保留她自身右侧的金色几何发夹和蓝金长耳坠，正面对应画面左侧。
- **衣装**：白色宽披领、层叠而不对称的白色外裙，深灰黑色内衬及颈饰；她左肩的金色护肩、分节金护臂、青蓝胸饰与蓝色垂带。白色鞋靴与金色细带作适合小尺寸的概括。
- **剑与尾**：缩小蓝色窄剑身和金色护手，由左手持续握持并向下收在身体附近。细长深蓝尾巴保持与下背部连接，不加恶魔式金属尖饰。
- **配色与画法**：冰蓝、白、石墨黑、浅金，少量青蓝。清楚的深色细线与柔和赛璐璐明暗，维持成年角色的从容仪态；衣褶和饰件适度简化以适配 192 × 208 像素单元。
- **场景取舍**：精二图里的巨型蝠鲼、海潮、遗迹和星光作为角色背景记录，不绘入桌宠图集；可读铭文、界面、飘浮特效和投影同样省略，确保主体清楚且每帧完整。

这些是小尺寸同人改编的设计选择，不应把鞋靴、简化剑形等视作官方立绘逐项复刻。

## 动作说明

| 状态 | 桌宠中的表达 |
| --- | --- |
| 待机 | 平稳呼吸、眨眼和微小发尾随动 |
| 左右移动 | 各自绘制的短步交替，衣摆跟随；保留不对称饰件与持剑侧 |
| 挥手 | 用空着的右手小幅致意，左手继续握剑 |
| 跳跃 | 蓄力、离地、最高点、下降、站稳，保留真实垂直位移 |
| 受挫 | 轻微低头与肩颈放松，再恢复从容 |
| 等待输入 | 张开空手、期待地看向用户，耐心询问 |
| 正在工作 | 站定思考与细微手势，不是原地跑步 |
| 复查 | 轻微前倾审视、偏头、眨眼和克制点头 |
| 十六方向 | 下身与剑柄锚定，头颈和眼球自然带动俯仰与偏转 |

图集只导入视觉动画；这些资料不会自动赋予对话人格、语音、记忆或额外能力。
