# 祀 · Si

An unofficial *Arknights: Endfield* animated companion. Repository, package, file and website IDs use `arknights-endfield-si`. Her curious, proud but caring manner informs the animation; gestures and small-size costume simplifications are a fan interpretation. Original references remain in the private creation archive.

来源核对日期：2026-10-21。项目 ID、文件名与网站 ID 统一使用 `arknights-endfield-si`。所属作品为《明日方舟·终末地》（官方英文名 *Arknights: Endfield*），在角色目录中与《明日方舟》分别展示。

## 设定依据

官方介绍将祀归于宏山科学院，种族标为未公开。她通常被称为巨兽代理人，但官方也明确强调她拥有独立的自我，不能简单等同于巨兽或另一人的替身。她为宏科院及终末地提供支持，同时乐于追逐新科技、时尚与各地的新鲜事物。参见[官网干员情报](https://endfield.hypergryph.com/#operator)。

[华法琳 Wiki 的游戏档案及语音转录](https://warfarin.wiki/cn/operators/si)和[AKEData 干员数据](https://www.akedata.wiki/?plugin=v3_character&id=chr_0036_jsspsi)确认她是六星、寒冷属性、使用双手剑的辅助干员。她与宏山长期合作，也是缘缘庄的掌柜；绘画、造物与对新事物的兴趣贯穿她的表现。这里仅记录理解造型和性格所需的背景，不将高阶档案中的身世细节展开为剧透。

## 性格的层次

她的核心不是冷淡，而是**自信、有主见、爱新鲜，并且不愿轻易把关心说出口**。她习惯以有些年长者意味的姿态评价别人，偶尔拌嘴、逞强、捉弄人；面对真正的困难，又能提供可靠支持。档案中的好奇和游戏语音中对同伴休息、伤势的关切，使她的傲气与温暖可以同时成立。

她珍视陪伴，也会在意别人是否记住承诺、名字和相处的经历。受到夸奖或掩饰失误时的小小不自在，很适合通过眼神、轻咳般的掩唇手势、微微偏头来表现。桌宠因此采用“略带小得意的陪伴者”这一创作解读：思考时认真，等待时有一点催促，受挫后会重新振作，而不是持续生气或只有夸张卖萌。

## 十二张上传图与网站立绘的共同细节

1. **发型与颜色**：浅青绿至薄荷绿的长发，较深的青绿色阴影；齐刘海中带有深绿发束，两侧长鬓发框住脸，后侧为左右低位发髻，并有长发延伸。不是短发或只有单个发髻。
2. **角与耳朵**：两支深墨色、枝杈状的角，内部或边缘可见黄绿、金黄色；角有不规则的分叉，不能画成光滑弯曲的羊角。尖耳向左右伸出。
3. **眼睛与表情**：清澈的青蓝眼睛，保留星形亮部和原本细长的眼睑结构；红棕色眼线只作微小点缀。通常神情清醒、略显骄矜，笑意克制。部分同人图的星形瞳被夸张放大，不直接照搬成另一种眼球结构。
4. **额饰与颈部**：额前金属几何饰件及细链；黑色高领或颈饰、白色翻领片、细长的金属与深色垂饰。服装沿中轴组织，不改为胸前大蝴蝶结。
5. **主体衣装**：白色偏银灰的短连衣裙，青蓝色纵向饰边或细带、两列小方形金属扣、深色内衬与裙摆褶层。领口保留简化的菱形结构；以适合桌宠的小尺寸自然概括，不强化暴露或身体细节。
6. **手臂与肩饰**：双臂为深青灰色长手套及独立的袖部结构，带浅色水纹；肩侧有黑色卷曲的金属装饰、金色几何部件与黄色绳结。不能将肩部卷曲饰件误画为额外的角。
7. **左右关系**：她自身左腕戴浅黄色珠串并带青蓝色坠带，正面对应画面右侧；此处是不应随移动方向镜像交换的识别点。
8. **腿部与鞋**：浅色袜部、腿环与黑色短靴；靴子保留金属扣和较结实的轮廓。小尺寸改编保持完整着装与可读的双足落地。
9. **尾巴**：一条从身体后方连出的青绿色、有鳞片感的龙尾，较宽的尾部与深色边缘延伸后收尖；不能与长发混为一束，也不添加恶魔式箭头尾尖。
10. **背部装饰翼**：白色、深边框、带几何或鳞片式纹样的翼形结构是背部的装饰，语音也有对应解释。它与手臂的衣袖不同。桌宠采用折叠、紧靠身体的状态，不让翼面铺满单元格或与双臂脱离。
11. **战斗场景元素**：双手剑、巨型毛笔般的武器造型、悬浮玉块、墨魉、龙形意象与水墨景物用于理解她的能力，不作为每帧都漂浮在桌宠周围的装饰。为使主体清楚，桌宠以空手日常姿势表现，省略巨大武器与场景特效。

上述观察以默认官方立绘、游戏模型截图为主；同人图补充表情、配色和装饰可见性。手绘的笔触、背景、水印、字幕、UI 和同人画中的特殊光照不会被复制到图集中。

## 生成取舍与动作设计

采用与合集一致的精细动漫 Q 版，约 2.7 头身，清楚的细线、柔和赛璐璐明暗；保持青绿、白、深墨、金黄、少量青蓝的配色。将长发、折叠翼和龙尾收进紧凑轮廓，保证全部角尖、耳朵、手指、鞋和尾端完整。

| 动作 | 角色化表达 |
| --- | --- |
| 待机 | 平稳呼吸、一次自然眨眼、发尾和尾端轻微随动 |
| 左右移动 | 双向独立的八帧奔跑循环，加大迈步与摆臂幅度；手臂与对侧腿配合前摆，肘膝自然弯曲，左右腿真实交替；左腕珠串不换边 |
| 挥手 | 空手小幅招呼，略带“总算来了”的得意神情 |
| 跳跃 | 蓄力、离地、最高点、下降、落稳；保持身体大小与真实高度变化 |
| 受挫 | 微微鼓脸或掩唇，短暂别开目光后恢复，避免持续发怒 |
| 等待输入 | 空手轻摊、带一点催促的期待眼神，与待机区别明显 |
| 正在工作 | 站定凝神思考，微小指尖手势，体现专注与灵感；不原地跑步 |
| 复查 | 前倾审视、偏头确认、克制点头，不临时增加纸张、放大镜或 UI |
| 十六方向 | 下身、翼根和尾根锚定，头颈与完整眼球结构自然带动视线，双角随头转；全身不做转盘 |

图集导入的是视觉动画，不会自动为聊天加入性格、语音、记忆或能力。动作与简化衣饰属于同人改编，不是新的游戏设定。
