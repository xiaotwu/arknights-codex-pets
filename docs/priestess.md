# 普瑞赛斯角色分析与宠物创作设定

## 角色与创作依据

普瑞赛斯（Priestess）是《明日方舟》中的角色。本桌宠依据六张角色参考图制作，性格解读参考 PRTS 收录的游戏剧情原文。[萌娘百科角色页](https://zh.moegirl.org.cn/%E6%99%AE%E7%91%9E%E8%B5%9B%E6%96%AF)为原始参考入口；整理时该页面只返回 JavaScript 提示，未将未读取的正文作为已核实依据。

## 外形与气质
六张图稳定呈现深棕近黑长发、黑色编织发箍、略偏分的整齐刘海、灰紫眼睛；白色高领衬衣配黑色蝴蝶结，白灰长科研外套、深色短裙与连裤袜、银白鞋。胸前证件牌、深色袖口结构和衣摆构成研究员辨识度。图中表情较少夸张，主要是微笑、凝视、侧身回望与温柔握手。画面冷光和留白带来遥远、静谧感，但这些是视觉阅读，不是性格事实。

## 性格的双重性
《巴别塔》BB-7 的对话同时表现她理解博士的不安、不会责怪，以及对计划的确信、对博士站在自己一边的期待。因此本次将她解读为关切、亲近、理性、坚定且带执念的研究者；不会把她简化为纯粹甜妹或无条件治愈。她的安静并非缺乏意志，微笑也不消解决断力。陪伴动作应温柔而克制，思考时目光清醒，失败时是短暂低落和重新收拢心神。

来源：[《巴别塔》BB-7 阴影显现 行动前](https://prts.wiki/w/BB-7_%E9%98%B4%E5%BD%B1%E6%98%BE%E7%8E%B0/BEG)。[PRTS 剧情角色一览](https://prts.wiki/w/剧情角色一览)为维基编辑归纳，和游戏原文分开看待。

## 桌面改编
采用约三头身的全身日式 SD Q 版，细深色轮廓、柔和赛璐璐阴影。保留发箍、灰紫眼、黑领结、白外套、胸牌与淡紫裙边；简化松散绑带，取消手持终端以保证小尺寸轮廓与动作清晰。这些取舍是创作适配。

九种状态：安静呼吸眨眼；向屏幕右和左小跑；克制招手；轻跃；受挫低头；伸手等待回应；托腮专注处理任务；微微前倾检查成果。工作和检查不用额外道具或漂浮符号。十六方向由眼睛、脸部和头颈的自然转动表达，双脚与下身固定，脸始终可见。
